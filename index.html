How do conversions work?

Conversions are performed entirely in your browser using JavaScript and WebAssembly libraries. No files are uploaded to any server.

  • Images: canvas API
  • PDF: pdf.js and jsPDF
  • Documents: mammoth (DOCX), SheetJS (XLSX)
  • Video/Audio: MediaRecorder, Web Audio API, and if available, FFmpeg.wasm
  • 3D: three.js exporters
  • Archives: JSZip and libarchive.js

Why might some conversions fail?

Some formats require heavy processing or proprietary codecs that browsers cannot handle without additional server resources.

  • MP4/AVI/MOV video conversion needs FFmpeg.wasm, which requires SharedArrayBuffer (available on Vercel, not on GitHub Pages)
  • BLEND files can only be converted FROM, not TO (via Telegram Bot)
  • Creating RAR or 7z archives is not possible in browser; only extraction is supported
  • Very large files may exceed memory limits
  • Some OGG/Opus codecs may not be supported in Safari
  • Some external libraries (three.js, libarchive.js) may fail to load due to CDN MIME type issues

Why does the site sometimes fail?

The site is hosted on GitHub Pages. Some libraries may not load due to CDN restrictions.

  • Primary link: GitHub Pages
  • If the site doesn't work, check your internet connection or try again later
  • Some file conversions will be limited due to browser restrictions

How to download videos from YouTube, TikTok or Twitter?

Our Download from Link tool works for direct file links. YouTube, TikTok and Twitter block direct downloads due to CORS restrictions. For these sites, you can use external services like cobalt.tools.
