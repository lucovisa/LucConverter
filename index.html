Site Guide

LucConverter Logo

Click on "LucConverter" in the top left corner to open the developer's GitHub page.

  • Opens github.com/lucovisa in a new tab
  • See all projects by the developer
  • Check source code and contributions

Invisible Home Area

Between the logo and the Donate button there is an invisible clickable area. It takes you to the main page of the site. It also shows the current time with seconds.

  • Click anywhere in that empty space to go home
  • Time updates every second
  • No visual indication except the time text

Donate

Click on the "❤️ Donate" button in the top right corner to support the project.

  • Panel slides out from the right side
  • Copy crypto wallet addresses
  • ETH/USDT (ERC-20)
  • BTC (Bitcoin mainnet)
  • TON/USDT (The Open Network)
  • Click outside the panel to close it
  • "Support LucConverter" header is a link to the project's GitHub repository

File Converter

Click on File Converter to convert files between different formats.

  • PDF → TXT, HTML, JPG, PNG
  • Images → PNG, JPG, WebP, SVG, BMP, ICO
  • Images → Text (OCR)
  • Video → MP4, AVI, MOV, GIF, WebM
  • Video → Audio (MP3, WAV, OGG)
  • Video → Image (JPG, PNG)
  • Audio → MP3, WAV, OGG, AAC, FLAC, M4A
  • Audio → Video (MP4, WebM)
  • DOCX → TXT, HTML, PDF
  • XLSX → CSV, JSON, HTML
  • HTML → TXT, Markdown, PDF
  • Any file → ZIP
  • 3D: GLB → BLEND (rename only, not true conversion)

Unit Converter

Click on Unit Converter to convert between different units.

  • Color — HEX, RGB, HSL
  • Time Zones — convert time between zones, supports custom UTC offsets like +10 or -5
  • Weight — kg, lbs, oz, etc.
  • Temperature — Celsius, Fahrenheit, Kelvin
  • Distance — km, miles, meters, etc.
  • Duration — seconds, minutes, hours, days, weeks, months, years
  • Speed — km/h, mph, m/s
  • Area — m², km², acres, hectares
  • Volume — liters, gallons, m³
  • Pressure — Pa, bar, atm, PSI
  • Energy — J, kJ, calories, Wh
  • Power — W, kW, hp
  • Angle — degrees, radians
  • Fraction to Decimal
  • Roman Numerals
  • Number Systems — binary, octal, hex
  • Date Converter — ISO, Unix timestamp, week number
  • UUID Generator
  • Every converter has a Clear button

Link Converter

Click on Link Converter to work with links and codes.

  • URL Encoder/Decoder
  • QR Code Generator
  • QR Scanner — upload or drag QR image
  • Link Shortener
  • Link Lengthener
  • Password Generator — with character options
  • Random Number Generator
  • Hash Generator — SHA-1, SHA-256, SHA-512
  • Text to Binary
  • ASCII Converter

Currency Converter

Click on Currency Converter to convert between 100+ currencies.

  • Fiat currencies — USD, EUR, RUB, JPY, etc.
  • Cryptocurrencies — BTC, ETH, USDT, etc.
  • Real-time exchange rates via API
  • Swap button to switch currencies
  • Type a letter to search in dropdown

Media Shop

Click on Media Shop to edit audio and video.

  • Upload audio or video files
  • Trim — set start and end time
  • Convert — MP4, WebM, MP3, WAV, etc.
  • Volume control
  • Download original or converted
  • Note: Audio editing works fully in browser; video editing requires FFmpeg which may not load on GitHub Pages

Photoshop

Click on Photoshop to edit images.

  • Upload image
  • Brush — draw with color and size
  • Eraser — remove parts
  • Fill — fill area with color
  • Resize canvas
  • Filters — brightness, contrast, saturation, blur, sharpen
  • Download edited image

Text Editor

Click on Text Editor to write and edit text.

  • New, Open, Save, Print files
  • Bold, Italic, Underline formatting
  • Language selection: JavaScript, HTML, JSON, Python, Lua, SQL
  • Run code directly in browser (JavaScript, Python, Lua, SQL)
  • UPPERCASE, lowercase, Reverse
  • Sort lines, Remove duplicates
  • Word count
  • Find and Replace

Calculator

Click on Calculator to perform calculations.

  • Basic operations — +, -, ×, ÷
  • Percentage
  • Keyboard support
  • Backspace, Clear
